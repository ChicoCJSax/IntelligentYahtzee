Repo for Colby Sax's Fall 2025 Capstone Project.

Files can be downloaded and run inside of VSCode. Some libraries will need to be installed, such as Pygame and Counter, which can be done with pip install *.

Project was intended to be a way for me to search/learn/experiement with concepts I was unfamiliar with, and I hadn't gotten to explore in my classes, things like game logic and AI. This project served to be my introduction to those topics, as I learned what I could on my own about them.
